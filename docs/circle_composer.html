Circle Composer

Four circular sequencers, one score. A playhead sweeps each circle (full turn = 12 beats); notes fire as it passes. Set each circle's loop point, layer the patterns, hit record — the song transcribes itself.
Add notes: click the ring (free mode = anywhere, microtonal). Set loop: click where this circle's playhead restarts — on notes, on rests, or free. Each circle has its own loop and its own BPM. Click any placed note to edit its own sound in the Sound panel; new notes take the panel's current settings. Play auditions, Record writes the score.
